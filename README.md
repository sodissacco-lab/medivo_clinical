# Medivo Clinical

Offline-first clinical reference and decision-support app for clinicians in Uganda and across Africa.

Built with Flutter (Android, iOS, Web) and Supabase, following the UGA-MED Clinical Companion Product Blueprint v1.0.

## Build progress

- [x] Phase 1 · Foundation: theme, navigation, home dashboard, Supabase connection
- [x] Phase 2 · Accounts and roles: sign-up, sign-in, profiles, seven roles enforced in the database, audit log
- [x] Phase 3 · Content engine: review workflow, versions, history, Content studio, Batch 1 drafts loaded
- [x] Phase 4 · Offline engine: on-phone SQLite library, download packs, background sync, Essential Pack
- [x] Phase 5 · Diseases, Drugs, Laboratory, Radiology: reference lists, topic pages, section jumps, SI/conventional units, templates
- [x] Phase 6 · Universal search
- [x] Phase 7 · Clinical calculators
- [x] Phase 8 · Emergency protocols and clinical algorithms

- [x] Phase 10 · Drug interactions

- [ ] Phase 17 · Public API and store release

## Safety

Medivo Clinical supports clinical judgement; it does not replace it. All clinical content passes medical review before publication.
